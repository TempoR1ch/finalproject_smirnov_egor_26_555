# ValutaTrade Hub

Консольная платформа для отслеживания валютных курсов и симуляции торговли фиатными и криптовалютами.

## Возможности

- Регистрация пользователей и вход в систему.
- Управление виртуальным валютным портфелем.
- Добавление валютных кошельков и пополнение баланса.
- Покупка и продажа валюты за USD.
- Получение и обновление курсов через внешние API.
- Просмотр сохранённых курсов с фильтрацией.
- Хранение данных в JSON-файлах.
- Логирование действий и обработка ошибок.

## Технологии

- Python 3.12+
- uv — управление зависимостями и запуск проекта.
- Requests — HTTP-запросы к внешним API.
- PrettyTable — форматирование таблиц в консоли.
- JSON — хранение данных.


Запустите приложение одним из способов:

## Команды

### Регистрация и вход

```text
register --username <имя> --password <пароль>
login --username <имя> --password <пароль>
```

### Портфель

```text
show-portfolio
show-portfolio --base EUR
add-currency --currency BTC
deposit --currency USD --amount 1000
```

### Торговля

```text
buy --currency BTC --amount 0.01
sell --currency BTC --amount 0.01
```

Выбрана упрощённая учебная модель торговли: `buy` проверяет валюту и положительное количество, при необходимости создаёт кошелёк и увеличивает его баланс. USD при покупке не списывается. `sell` проверяет наличие кошелька и достаточность средств, уменьшает баланс и показывает оценочную выручку в USD; USD-кошелёк не пополняется. Для оценки выручки при продаже используется сохранённый курс.

### Валютные курсы

```text
get-rate --from USD --to EUR
update-rates
update-rates --source coingecko
update-rates --source exchangerate
show-rates
show-rates --currency BTC
show-rates --top 5
show-rates --base USD
```

Команда `update-rates` обновляет курсы. Параметр `--source` позволяет выбрать источник: `coingecko` или `exchangerate`.

### Справка и выход

```text
help
exit
```

## Источники курсов

- **CoinGecko** — курсы поддерживаемых криптовалют.
- **ExchangeRate-API** — курсы поддерживаемых фиатных валют.

Для ExchangeRate-API нужен API-ключ в переменной окружения `EXCHANGE_RATE_API_KEY`. В PowerShell задайте его для текущего окна перед запуском:

```powershell
$env:EXCHANGE_RATE_API_KEY = "ваш_api_ключ"
uv run python main.py
```

Для другого срока актуальности кэша задайте `RATES_TTL_SECONDS` (по умолчанию 300 секунд). Например: `$env:RATES_TTL_SECONDS = "600"`. Команда `get-rate` использует свежие данные кэша и пытается обновить их, если нужный курс отсутствует или устарел. Ошибка одного источника не удаляет сохранённые курсы этого источника; если оба источника недоступны, обновление завершается ошибкой и существующий кэш сохраняется.

## Хранение данных

Приложение использует JSON-файлы в каталоге `data/` (каталог создаётся автоматически):

- `users.json` — список пользователей с идентификатором, логином, датой регистрации, солью и хэшем пароля; исходные пароли не сохраняются.

Пароли защищены алгоритмом **PBKDF2-HMAC-SHA256** с индивидуальной случайной солью и 100 000 итерациями. В `users.json` сохраняются только соль и хэш, исходный пароль не записывается.
- `portfolios.json` — портфели по `user_id`, содержащие словарь кошельков и балансы.
- `rates.json` — объект с `last_refresh` и словарём `pairs`; каждая пара (например, `BTC_USD`) содержит `rate`, `updated_at` и `source`.
- `exchange_rates.json` — история обновлений; каждая запись содержит уникальный `id`, валюты пары, курс, временную метку и источник.

JSON-файлы записываются атомарно через временный файл и замену. `data/` и `logs/` исключены из Git, чтобы не публиковать пользовательские данные, кэш и логи.

## Структура проекта

- `valutatrade_hub/core/` — модели и бизнес-логика.
- `valutatrade_hub/cli/` — консольный интерфейс.
- `valutatrade_hub/parser_service/` — получение и хранение валютных курсов.
- `valutatrade_hub/infra/` — настройки и работа с хранилищем.
- `valutatrade_hub/decorators.py` — логирование и измерение времени выполнения.
- `valutatrade_hub/logging_config.py` — настройка логирования.
- `main.py` — точка входа.
